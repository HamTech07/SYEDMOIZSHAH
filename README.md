# Syed Moiz Ahmed — Game Developer Portfolio

A responsive React portfolio for Syed Moiz Ahmed, built with Vite. It highlights Unity and C# game development, Blender work, and the Android game builds from the supplied Drive folder.

## Run locally (Windows PowerShell)

```powershell
cd C:\Users\HAMTECH07\Desktop\client
npm.cmd run dev
```

If dependencies need to be installed again, run `npm.cmd install` first. To create a production build, run `npm.cmd run build`.

The APK buttons open the builds in the supplied Google Drive folder. Game covers and social brand marks load from their shared image links and Simple Icons.
